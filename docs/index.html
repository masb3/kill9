The same thing, without the incantation.

Every developer has typed this from memory, got it slightly wrong, and typed it again. Kill9 is that command with a window around it.

Small on purpose.

One window in the menu bar. It does one job well, then gets out of the way.

Every port at a glance
Listening TCP and bound UDP ports, IPv4 and IPv6 merged into one row. Refreshes every 3 seconds while open.
Port, then Return
Type a port number and press Return to stop everything using it. Search also matches app names, process names and PIDs.
Gentle first, firm second
Kill sends SIGTERM so servers can shut down cleanly, then SIGKILL after 1.5 seconds if they don't. Force Kill sends -9 straight away.
Grouped by app
Helper processes roll up into their parent app, so Docker or your IDE shows up once with all its ports.
Know what you're stopping
Process name, app icon, PID, user, and whether it listens on localhost only or on every network interface.
Right-click for more
Open the port in your browser, copy the PID or the kill command, or reveal the program in Finder.

Install in a minute.

Kill9 isn't notarized by Apple yet, so macOS asks you to confirm the first launch. You only do this once.

  1. Download Kill9.dmgGet the latest release and double-click it to open.
  2. Drag it to ApplicationsDrag Kill9 onto the Applications folder in the window that opens. If you skip this, Kill9 offers to move itself when you first open it.
  3. Allow it to open Run this once in Terminal. Or try to open the app, then click Open Anyway in System Settings → Privacy & Security.
    xattr -dr com.apple.quarantine /Applications/Kill9.app
  4. Open Kill9The ⑨ icon appears in your menu bar. There's no Dock icon. Turn on Launch at login if you want it there every day.

Rather build it yourself? Clone the repo and run ./build-app.sh. That also works on Intel Macs. You need macOS 13 or later and the Xcode Command Line Tools. Kill9 can only stop processes owned by your user; for root-owned ones it shows the sudo kill -9 command to run instead.

Next time a port is taken, it takes one keystroke.
